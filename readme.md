# Simple Minecraft Stack Calculator With Right Russian Declination.
## Простейший Калькулятор Стаков Для Minecraft С Правильным Русским Склонением.

---
Эта штука позволяет просчитывать, сколько шалкеров, стаков и предметов в общем
количестве предметов. Я это сделал себя и удобной работы с модом для Minecraft - Litematica,
который сохраняет необходимые ресурсы в .txt документ БЕЗ разложения на шалкеры и стаки...

### Использование  
Скачайте последний релиз.  
Откройте папку, куда загрузилась программа и наберите `java -jar smsc-v1.1.jar целое_число`
